

# もし株

「もし株」は、買おうか迷ったものの実際には買わなかった株を記録し、後日「もしあのとき買っていたらどうなっていたか」を答え合わせするスマホアプリです。

デザイン方針は以下を基本とします。

- クリーム系のやわらかい背景
- 緑をメインカラー
- 少し可愛い雰囲気
- 角丸カード中心
- 猫キャラクターを案内役として使う
- 情報を詰め込みすぎない
- 株価や騰落率などの数字は読みやすさを優先する

## 開発方針

- FlutterでiOS / Androidアプリとして開発
- Web版は先に作らない
- MVPではログインなし
- データは端末内保存
- 株価取得は開発初期にyfinanceを利用
- 保有株管理や売買機能は実装しない
