

# もし株 ROADMAP

## 開発方針

「もし株」は、買おうか迷ったものの実際には買わなかった株を記録し、後日「もし買っていたらどうなっていたか」を答え合わせするスマホアプリ。

Web版を先に作らず、最初からFlutterでiOS / Androidアプリとして開発する。

MVPでは機能を増やしすぎず、以下のコア体験を最優先する。

**迷う → 見送る → すぐ記録する → 忘れる → 通知で思い出す → 答え合わせする**

## Phase 5: 端末内保存

### Task 008: ローカルデータ保存

1件のもし株について以下を保存する。

- 銘柄コード
- 銘柄名
- 見送り価格
- 記録日時
- 見送った理由
- その他自由記述
- 答え合わせ予定日
- 答え合わせ価格
- 答え合わせ済み / 未実施状態

MVPではログインやクラウド同期は実装しない。

### Task 009: 最近のもし株一覧

- 保存済みデータをホーム画面に表示
- 新しい順に表示

## Phase 6: 答え合わせ

### Task 010: 答え合わせ日判定

- 記録日から設定期間後の日付を算出
- 土日祝など非取引日の場合は次の取引日に繰り越す
- 答え合わせ対象になった記録を判定

### Task 011: 答え合わせ価格取得

- 答え合わせ日の終値を取得
- 記録時価格との騰落率を計算
- 終値取得前は答え合わせ未確定として扱う

### Task 012: 答え合わせ画面

- 記録時価格
- 答え合わせ日の終値
- 騰落率
- 見送った理由
- 記録日時
- 答え合わせ日
- 「もし買っていたら +○% / -○%」と表示
- 正解 / 不正解の判定は表示しない

## MVP後の候補

### 学習画面

記録した「見送った理由」と、その後の値動きを集計し、自分の判断傾向を振り返れるようにする。

例：

- 「高いと思った」で見送った株のその後の上昇率
- 「まだ下がりそう」で見送った株のその後の下落率
- 見送り理由ごとの回数
- 自分が見送りやすい判断パターン

学習画面はMVPには含めず、MVPで蓄積したデータを利用して後から追加する。
