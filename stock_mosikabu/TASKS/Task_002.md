

# Task 002: ホーム画面UIをモックへ寄せる

## 目的

Task 001で作成したホーム画面の骨組みを、初期UIモックの雰囲気へ近づける。

今回は機能追加ではなく、ホーム画面の見た目・余白・可愛さ・情報の見せ方を整えることに集中する。

参照するUIモック：

`docs/mockups/moshi_kabu_ui_mock_v1.png`

## 実装範囲

### 1. 猫キャラクター表示

- `docs/mockups/moshi_kabu_ui_mock_v1.png` に描かれている猫キャラクターを、今回の猫デザインの最優先リファレンスとする
- モック内の猫の、白〜クリーム系の体色、黒〜茶系の細い輪郭、丸くやさしい顔、シンプルな目と口、少しゆるい手描き風の雰囲気にできるだけ寄せる
- ホーム画面では、モック1画面目の「本を持っている猫」の雰囲気を参考にして、案内役として自然に見えるように配置する
- 猫の表情は、親しみやすく、少し可愛いが幼すぎないものにする
- 可能であれば、モック内の猫キャラクターの見た目をそのまま再現する方向で実装してよい
- 実装方法はFlutter標準Widget、CustomPaint、簡単なベクター表現など、後から正式素材へ差し替えやすい方法を優先する
- 現在の肉球プレースホルダーは廃止する
- 猫は単なる飾りではなく、今後も吹き出しや通知・答え合わせ画面で案内役として継続利用する前提とする

### 2. 猫の吹き出し

- モックのように、猫が話しているように見える吹き出しへ調整する
- 文言は以下を基本とする

  `今日は気になる株あった？`

- 文字は読みやすく、可愛すぎて幼くなりすぎないバランスにする

### 3. ヘッダー

- アプリ名「もし株」を見やすく配置する
- 上部余白を調整し、モックのようにすっきりした印象にする
- 不要な情報は追加しない

### 4. 「もし株を記録する」ボタン

- 緑をメインカラーとして維持する
- モックのように丸みのある大きなボタンにする
- 押したくなる見た目にする
- ボタン内のアイコンと文字のバランスを調整する
- 今回は押下後の画面遷移は実装しない

### 5. 「答え合わせ待ち」カード

- 角丸カードを維持する
- アイコン、見出し、説明文の余白を整える
- 現時点では空状態のままでよい
- 空状態でも寂しく見えないデザインにする

表示文言の例：

- 見出し：`答え合わせ待ち`
- 説明：`答え合わせできるもし株がここに表示されます`

### 6. 「最近のもし株」カード

- 角丸カードを維持する
- アイコン、見出し、説明文の余白を整える
- 現時点では空状態のままでよい

表示文言の例：

- 見出し：`最近のもし株`
- 説明：`記録したもし株がここに表示されます`

### 7. 全体レイアウト

以下を意識して調整する。

- クリーム系のやわらかい背景
- 緑をメインカラー
- 角丸カード
- 余白を広めに取る
- 情報を詰め込みすぎない
- 少し可愛いが、投資アプリとして数字や文字は読みやすくする
- モックの雰囲気へ寄せる
- iPhoneで見たときに縦方向のバランスが自然になるようにする

## 実装上の注意

- Task 001で作った構成を必要以上に崩さない
- UI部品は後のTaskで再利用しやすい形にする
- 将来機能を先回りして実装しない
- `docs/mockups/moshi_kabu_ui_mock_v1.png` を必ず確認し、特に猫キャラクターについては最優先のデザイン基準として参照する
- 猫キャラクターを独自デザインへ変更せず、モック内の猫にできるだけ忠実に寄せる
- モックを完全コピーする必要はないが、配色・余白・可愛さ・カードの雰囲気を合わせる
