# 6. 答え合わせ一覧

実機画面で確認された最優先UI調整ポイント。

## 長い銘柄名

例：

```text
キオクシアホールディングス
```

現在、一部端末幅では2行表示になり、やや詰まって見える。

Task 017で以下を確認し、必要最小限の調整を行う。

- StockIcon
- 銘柄コード
- 銘柄名
- 騰落率バッジ

が互いに干渉しないこと。

銘柄名は最大2行を許容する。

2行になった場合も、下の価格表示との間隔が不足しないようにする。

騰落率バッジを圧迫しないよう、銘柄名領域をFlexible / Expanded等で適切に扱う。

フォントサイズを極端に小さくして解決しない。

## 価格表示

```text
48,240円 → 52,090円
```

の左右バランスを維持する。

桁数が大きい株価でも画面外へはみ出さないこと。
