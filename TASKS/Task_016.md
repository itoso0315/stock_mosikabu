
# Task 016: 銘柄アイコン共通化

## 目的

「もし株」の各画面で、銘柄名・銘柄コードだけでなく、会社名をもとにした共通の銘柄アイコンを表示し、銘柄を直感的に識別しやすくする。

Task 016では、外部APIやCDNは使用せず、既存の会社名から先頭文字を生成して表示する共通アイコンを実装する。

MVPでは会社ロゴそのものは使用しない。

---

# 基本方針

外部ロゴサービス、外部API、CDN、企業公式サイトの画像取得は使用しない。

理由：

- 外部サービス登録を増やさない
- API料金や無料枠を気にしなくてよい
- サービス終了や料金変更の影響を受けない
- オフラインでも表示できる
- 日本株の全銘柄に同じルールで対応できる
- 商標・ロゴ利用規約の確認コストを減らせる

既存の `companyName` から表示文字を生成し、共通Widgetとして各画面で利用する。

想定フロー：

```text
companyName
↓
不要な会社種別表記を除去
↓
先頭の表示文字を取得
↓
共通StockIcon Widgetで表示
```

---

# 1. アイコン表示対象画面

以下の画面で同じ共通アイコンWidgetを利用する。

- ホーム「最近のもし株」
- 未完了記録一覧
- 答え合わせ一覧
- 答え合わせ詳細
- 振り返り一覧
- 振り返り詳細

既存UIとのバランスを見て、基本的に銘柄名の左側へ表示する。

アイコンサイズ、角丸、文字スタイルは画面ごとに個別実装せず、共通Widget側で統一する。

---

# 2. 共通Widget

銘柄アイコン表示用の共通Widgetを作成する。

仮名称：

```text
StockIcon
```

最低限以下を受け取れる設計とする。

- companyName
- stockCode
- size

`stockCode` は将来ロゴ表示へ拡張する可能性を考慮して受け取れる設計にしてよいが、Task 016では外部取得には使用しない。

画面ごとに先頭文字生成ロジックを重複実装しない。

---

# 3. 表示文字生成ルール

会社名から、ユーザーが見て自然な先頭1文字を取得する。

基本例：

```text
トヨタ自動車 → ト
任天堂 → 任
ソニーグループ → ソ
NTT → N
三菱UFJフィナンシャル・グループ → 三
```

英字で始まる場合は先頭英字を大文字で表示する。

例：

```text
ntt → N
ZOZO → Z
```

ひらがな、カタカナ、漢字はそのまま先頭1文字を使用する。

---

# 4. 会社種別表記の除去

会社名の先頭に会社種別を示す表記が含まれている場合、それを除外してから表示文字を決める。

少なくとも以下を考慮する。

- 株式会社
- （株）
- (株)
- ㈱

例：

```text
株式会社トヨタ自動車 → ト
（株）任天堂 → 任
```

会社種別表記を除去した結果が空になる場合は、安全なフォールバックを使用する。

既存のJPX銘柄マスタの会社名形式を確認し、過剰な変換処理は追加しない。

---

# 5. フォールバック

`companyName` が空、null相当、または有効な表示文字を取得できない場合でもクラッシュしない。

フォールバック優先順位：

```text
会社名から先頭文字
↓
銘柄コードの先頭文字
↓
?
```

例：

```text
companyNameなし / stockCode = 7203
→ 7

companyNameなし / stockCodeなし
→ ?
```

空白やbroken表示にはしない。

---

# 6. デザイン

「もし株」の既存デザインへ自然に馴染ませる。

基本方針：

- クリーム系または淡い背景
- 緑系アクセント
- 角丸または円形に近い形
- 中央に1文字
- 太すぎないが視認性の高いゴシック系文字
- 少し可愛いが幼すぎない
- 会社名より主張しすぎない

一覧画面では小さめ、詳細画面では必要に応じて少し大きく表示してよい。

ただし基本デザインは共通Widget側で統一する。

---

# 7. 色

Task 016では銘柄ごとにランダムカラーを生成しない。

原則として「もし株」の既存テーマカラーを使い、全銘柄で統一感を優先する。

将来的に業種別カラーや銘柄ごとの色分けを追加できる設計は妨げないが、MVPでは実装しない。

---

Task 016では会社ロゴ取得そのものは実装しない。
