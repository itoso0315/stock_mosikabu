

# Task 007: 答え合わせ期間設定

## 目的

Task 006で仮表示している `答え合わせ：1か月後` をユーザーが変更できるようにする。

今回は「いつ答え合わせするか」を選択し、その内容を見送り記録のドラフトへ保持するところまでを実装する。

端末内への本保存、土日祝の取引日補正、通知、答え合わせ日の終値取得はまだ実装しない。

UIの基準は引き続き以下のモックとする。

`docs/mockups/moshi_kabu_ui_mock_v1.png`

---

## 実装範囲

### 1. 答え合わせ期間表示をタップ可能にする

Task 006の見送り記録画面にある以下の表示をタップ可能にする。

`答え合わせ：1か月後`

表示方針：

- 現在のカードデザインを維持する
- 右側に小さく `変更` または `>` を表示してよい
- タップ可能であることが自然に分かるUIにする
- 画面全体の可愛い・やわらかい雰囲気を壊さない

### 2. 選択できる期間

以下の選択肢を用意する。

- 3日後
- 1週間後
- 1か月後
- 3か月後
- カスタム

初期値は以下とする。

`1か月後`

### 3. 期間選択UI

答え合わせカードをタップした際、期間を選択できるUIを表示する。

実装方法は、以下のいずれかのシンプルな方法でよい。

- BottomSheet
- ModalBottomSheet
- 小さな選択画面

iPhoneで自然に見え、1〜2タップで変更できる方法を優先する。

選択肢は縦に並べ、現在選択中の項目が分かるようにする。

### 4. 通常期間の選択

`3日後 / 1週間後 / 1か月後 / 3か月後`

のいずれかを選択した場合：

- 選択内容を画面へ即時反映する
- 見送り記録画面へ戻った際にも選択内容を維持する
- `SkipRecordDraft` 等のドラフトへ保持する

表示例：

`答え合わせ：1週間後`

### 5. カスタム選択

`カスタム` を選択した場合、具体的な答え合わせ日を選択できるようにする。

今回は「何日後」ではなく、具体的な日付選択を採用する。

実装方針：

- Flutter標準の日付ピッカーを使用してよい
- 過去日は選択できないようにする
- 今日を答え合わせ日にする選択は不可とする
- 明日以降の日付を選択できるようにする
- 選択した日付をドラフトへ保持する

表示例：

`答え合わせ：2026/09/18`

### 6. 内部データ構造

答え合わせ期間は、将来の保存・通知・取引日補正に使える形で保持する。

例：

- preset type
  - 3days
  - 1week
  - 1month
  - 3months
  - custom
- customDate

表示文言と内部値は分離する。

将来、期間選択肢の文言を変更しても保存データに影響しにくい構造にする。

### 7. 見送り記録ドラフトへの反映

Task 006で用意した `SkipRecordDraft` に答え合わせ設定を保持できるようにする。

最低限保持する情報：

- 答え合わせ期間の種類
- カスタムの場合の指定日

今回はまだ端末内DBへ保存しない。

## UI方針

- クリーム系背景
- 緑をメインカラー
- 角丸カード
- 丸みのある柔らかいゴシック系の文字
- 明朝体っぽい細い文字は使わない
- BottomSheet等を使う場合も、既存画面の可愛い雰囲気に合わせる
- 選択肢を詰め込みすぎない
- 変更操作は短時間で完了できるようにする

## 今回やらないこと

- 端末内DBへの本保存
- 記録完了画面
- 答え合わせ日の土日祝補正
- 日本の祝日判定
- 次の取引日への繰り越し
- 答え合わせ日の終値取得
- 通知
- 学習分析
- ログイン
- 保有株管理
- 株式売買

## 実装上の注意

- Task 006までの見送り記録画面を壊さない
- 見送り理由選択、自由記述、株価取得、戻る操作を維持する
- 答え合わせ設定は固定文字列ではなく、将来利用できる内部値で保持する
- カスタム日付は過去・当日を選択不可とする
- 大きな状態管理ライブラリは導入しない
- Task 007の範囲外を先回り実装しない

## テスト

最低限、以下を確認する。

- 初期表示が `答え合わせ：1か月後` になっている
- 答え合わせカードをタップすると期間選択UIが開く
- 3日後を選択できる
- 1週間後を選択できる
- 1か月後を選択できる
- 3か月後を選択できる
- 選択内容が見送り記録画面へ反映される
- カスタムを選ぶと日付ピッカーが開く
- 過去日・当日を選択できない
- カスタム日付が画面へ反映される
- 選択内容が `SkipRecordDraft` に保持される
- iOS Simulatorでオーバーフローしない
