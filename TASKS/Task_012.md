

# Task 012: 振り返りタブ実装

## 目的

Task 011までで、答え合わせ結果を取得・保存し、確認済みの記録を `completed` / 振り返り対象として扱えるようになった。

Task 012では、下部ナビの `振り返り` タブを本実装し、答え合わせ済みの記録をあとから一覧で見返せるようにする。

今回のゴールは、

**答え合わせ済み記録を一覧で見返す → 必要なら詳細画面を再表示する**

という基本体験を完成させること。

学習分析、傾向分析、グラフ、勝率・正解率のような評価機能はまだ実装しない。

---

## 画面の役割

`振り返り` タブは、すでに答え合わせ結果を確認した記録だけを見る場所とする。

役割分担：

- ホーム：現在の記録・最近のもし株
- ベル / 答え合わせ：今確認すべき答え合わせ結果
- 振り返り：すでに確認済みの答え合わせ結果をあとから見返す場所

未答え合わせの記録は振り返りタブへ表示しない。

---

## 実装範囲

### 1. 下部ナビの「振り返り」をタップ可能にする

現在の下部ナビにある `振り返り` タブを本実装する。

タップ時に振り返り画面へ切り替わるようにする。

既存のホーム・設定タブとの切り替えを壊さない。

### 2. 振り返り対象データ

端末内に保存された `SkipRecord` のうち、答え合わせ結果の取得・保存が完了している記録だけを表示する。

対象の考え方：

- `completed`
- 答え合わせ価格が保存済み
- 騰落率が保存済み

既存モデルの実装に合わせて判定する。

未答え合わせ、取得失敗、未確認の記録は表示しない。

### 3. 一覧の並び順

振り返り一覧は、新しい答え合わせ結果から順に表示する。

第一候補：

`答え合わせ実行日時の降順`

それが存在しない古いデータでは、記録日時等を安全なフォールバックとして使ってよい。

### 4. 振り返りカードの表示内容

各カードには最低限以下を表示する。

- 銘柄コード
- 銘柄名
- 見送り価格
- 答え合わせ価格
- 騰落率
- 見送り理由
- 答え合わせ期間

表示イメージ：

```text
三菱UFJフィナンシャル・グループ
8306

3,515円 → 3,780円

+7.5%
1か月後

高いと思った
```

情報を詰め込みすぎず、一覧で結果を直感的に理解できることを優先する。

### 5. 騰落率の色分け

Task 011の答え合わせ一覧・詳細画面と同じ色ルールを使用する。

- プラス：ピンク〜赤系
- マイナス：水色〜青系
- 0%付近：グレー系

色ルールを画面ごとにバラバラに定義しない。

既存の共通処理やスタイルを再利用できる場合は再利用する。

### 6. 騰落率を目立たせる

振り返りカードでは、騰落率を視認しやすいピルまたは小さめの強調表示にする。

例：

`+12.6%`

`-8.7%`

ただし、銘柄名や見送り価格より極端に大きくしすぎない。

### 7. カードタップで既存の答え合わせ詳細画面へ遷移

振り返りカードをタップすると、Task 011で実装済みの答え合わせ結果詳細画面へ遷移する。

保存済み結果を使用し、APIへ再取得しない。

表示する内容はTask 011の既存詳細画面を再利用する。

新しい重複した詳細画面を作らない。

### 8. 詳細画面から戻る

詳細画面の戻る操作で、振り返り一覧へ自然に戻れるようにする。

不要にホームへ戻ったり、Navigation stackがおかしくならないようにする。

### 9. 0件時の空状態

completed記録が0件の場合、空白画面にしない。

例：

`まだ振り返れる記録はありません`

補足文例：

`答え合わせが終わると、ここに記録が並びます`

既存の猫キャラクターまたは小さなアイコンを使用してよい。

新しい別デザインの猫は作らない。

### 10. 画面タイトル

画面上部に

`振り返り`

を表示する。

下部ナビでも `振り返り` が選択中であることを分かりやすくする。

### 11. 下部ナビ状態

振り返り画面表示中は、下部ナビの `振り返り` を選択状態にする。

ホームをタップすればホームへ戻れる。

設定をタップすれば設定へ移動できる。

既存のナビゲーション構造を必要以上に作り直さない。

### 12. データ更新

Task 011で新しい答え合わせ結果がcompletedになったあと、振り返りタブへ移動すると、その記録が一覧へ反映されること。

アプリを完全再起動しなくても最新状態を読み込めるようにする。

### 13. 保存済み結果の利用

振り返りタブでは、保存済みの以下の情報を使用する。

- answer price
- price date
- return rate
- answer executed datetime
- completed state

振り返り一覧を開くたびに株価APIへ再アクセスしない。

### 14. 古い保存データへの配慮

Task 011以前から保存されている古いデータで、答え合わせ結果フィールドが存在しない場合もクラッシュしない。

completed条件を満たさない古い記録は振り返り一覧へ出さなくてよい。

## UI方針

- クリーム系背景
- 緑を基本カラー
- 大きめの角丸カード
- 柔らかいゴシック系
- 明朝体っぽい細い文字は使用しない
- 少し可愛いが幼すぎない
- プラス / マイナスの色を結果部分だけに使う
- 1画面で複数記録を見比べやすい
- 情報を詰め込みすぎない
- Task 011の答え合わせ画面と世界観を統一する
