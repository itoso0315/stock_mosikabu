

# Task 014: 振り返り検索・フィルター・ソート

## 目的

Task 012で実装した `振り返り` タブは、答え合わせ済みの記録を新しい順に一覧表示できる。

今後記録件数が増えると、特定の銘柄・特定の見送り理由・プラス／マイナス結果を探しにくくなるため、Task 014では振り返り一覧へ検索・絞り込み・並び替えを追加する。

今回のゴールは、

**振り返り記録を探す → 条件で絞る → 好きな順で並べる**

という基本操作を、iPhoneで少ないタップ数で行えるようにすること。

---

## 実装範囲

### 1. 振り返り画面上部に検索UIを追加

振り返り画面の上部に、銘柄を検索できる検索欄を追加する。

プレースホルダー例：

`銘柄名・コードで検索`

検索対象：

- 銘柄名
- 銘柄コード

入力中にリアルタイムで一覧へ反映する。

検索ボタン押下を必須にしない。

### 2. 銘柄名・コード検索

会社名は部分一致で検索できるようにする。

例：

- `三菱` → 三菱UFJフィナンシャル・グループ
- `フジ` → フジクラ等
- `NTT` → NTT

銘柄コードは前方一致または部分一致で検索できるようにする。

例：

- `8306`
- `83`
- `285A`

Task 010の検索正規化処理を再利用できる場合は再利用する。

### 3. 右上にフィルター（ろうと）アイコンを追加

振り返り画面右上に、ろうと形のフィルターアイコンを追加する。

タップするとBottomSheet等で絞り込み条件を設定できるようにする。

フィルターアイコンは、検索欄より目立たせすぎない。

### 4. フィルター条件① 結果

答え合わせ結果で絞り込みできるようにする。

選択肢：

- すべて
- プラス
- マイナス
- 横ばい

初期値：

`すべて`

判定はTask 011・012で使用している騰落率ルールと統一する。

### 5. フィルター条件② 見送り理由

見送り理由で絞り込みできるようにする。

選択肢：

- すべて
- 高いと思った
- まだ下がりそう
- 材料・地合いが不安
- 資金を温存したい
- その他

初期値：

`すべて`

内部enum / IDを利用し、表示文言だけで判定しない。

### 6. 並び順

振り返り一覧の並び順を変更できるようにする。

選択肢：

- 新しい順
- 古い順
- 騰落率が高い順
- 騰落率が低い順

初期値：

`新しい順`

`新しい順 / 古い順` は答え合わせ実行日時を基準とする。

既存データで答え合わせ実行日時がない場合は、記録日時等を安全なフォールバックとして利用してよい。

### 7. 検索・フィルター・ソートを同時適用

以下は同時に利用できるようにする。

例：

- 銘柄検索：`三菱`
- 結果：プラス
- 見送り理由：高いと思った
- 並び順：騰落率が高い順

条件適用順は内部実装上分かりやすい形でよいが、最終表示が全条件を満たすこと。

### 8. フィルターBottomSheet

フィルターアイコンをタップした際、BottomSheet等で以下をまとめて設定できるようにする。

- 結果
- 見送り理由
- 並び順

UI方針：

- 1画面に詰め込みすぎない
- 現在選択中の条件が分かる
- `適用` ボタンを設けてもよい
- `リセット` を用意する

### 9. フィルター適用状態を分かりやすくする

`すべて / 新しい順` 以外の条件が1つでも適用されている場合、フィルターアイコンに小さなドットやバッジを表示してよい。

ユーザーが「現在絞り込み中」であることを見失わないようにする。

### 10. 検索結果0件時

条件に一致する振り返り記録が0件の場合、空白にしない。

表示例：

`条件に合う振り返りがありません`

補足文例：

`検索条件やフィルターを変えてみてください`

必要であれば `条件をリセット` ボタンを表示してよい。

### 11. 通常の0件状態と区別する

completed記録そのものが0件の場合：

`まだ振り返れる記録はありません`

completed記録は存在するが検索条件で0件の場合：

`条件に合う振り返りがありません`

と区別する。

### 12. 既存カード表示を維持

Task 012で実装した振り返りカードの以下は変更しない。

- 銘柄コード
- 銘柄名
- 見送り価格
- 答え合わせ価格
- 騰落率
- 見送り理由
- 答え合わせ期間
- プラス / マイナス / 横ばいの色分け
- カードタップで既存の答え合わせ詳細画面へ遷移

Task 012の追加UI修正で会社ロゴ表示が実装済みの場合、その表示も維持する。

### 13. 状態保持

振り返り詳細画面を開いて戻った場合、検索文字・フィルター条件・並び順を維持する。

下部ナビでホーム等へ移動して戻った際の保持は、現在のナビゲーション構造で自然に実装できる範囲で行う。

アプリ再起動後まで検索条件を永続保存する必要はない。

### 14. フィルター・ソートロジックの分離

検索・フィルター・並び替えロジックを `review_screen.dart` 内へ大量に直書きしない。

例：

- `ReviewFilter`
- `ReviewSortOrder`
- `ReviewFilterService`

等へ分離してよい。

将来条件を追加しやすい構造にする。

## UI方針

- クリーム系背景
- 緑を基本カラー
- 柔らかいゴシック系
- 大きめの角丸
- 明朝体っぽい細い文字は使わない
- フィルターUIを主役にしすぎない
- 一覧の見やすさを最優先する
- iPhoneで片手操作しやすい
- BottomSheetは小さい画面でもスクロール可能にする
- 既存の答え合わせ・振り返り画面との統一感を維持する

- Task 013までの振り返り・分析・答え合わせ機能を壊さない
